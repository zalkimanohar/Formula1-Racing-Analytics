Rank the drivers the way a broadcast ranks a race. Raw points favour the modern era, where a win is worth 25; the era-adjusted score counts every race as a share of the winner's haul, so a win is worth exactly 1 in any decade.

          Ask the data

          Ask about any driver, team, circuit or season, in English or Spanish. Llama 3 writes the answer on this computer, but it may only use the evidence beside it: exact figures computed from the cleaned dataset, the team-mate network and our podium model, each traced to its file and raw line. Every number in the answer is then checked against that evidence.

          Connecting to the assistant

          1. UnderstandFinds drivers, teams, circuits and seasons in the question
          2. Gather evidenceExact figures, team-mate chains, model estimates, documents
          3. WriteLlama 3 answers from the evidence only and cites it
          4. CheckEvery figure in the answer is looked up in the evidence

          Pick an example or type your own question. The evidence appears first, in under a second; the written answer follows.

          About this page

          Race results from the Ergast Developer API, served by Jolpica-F1 and licensed under CC BY-NC-SA 4.0. Cleaned, validated and documented by for Data Management, Winter 2026/27, SRH University.

          Points are shown as awarded under each season's rules. Era-adjusted scores, outcome groups and team families are our own derivations, documented in the project report.

          Rebuild it

          Everything here is generated from the cleaned dataset in data_management_project. Run python run_all.py, then python dashboard/build_web_data.py.

          The assistant runs locally: python -m src.assistant.api inside data_management_project, with Ollama and ollama pull llama3. Its idea and first prototype come from Manohar Zalki's Graphic-LlmRag.
